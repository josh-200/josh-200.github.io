Archivo y tipo de datos

Funciona localmente en Chrome/Edge. El archivo no se envía a internet.
Ej.: si los títulos de columnas están en la fila 3, escribe 3.
Selecciona un archivo para comenzar.
Importación independiente: los nombres de las columnas no tienen que coincidir con la página. Después de leer el archivo podrás indicar, por ejemplo, que “VALOR” significa Precio o que “CEL” significa WhatsApp.
Para una importación sencilla: puedes relacionar Cliente, Precio/Total y Estado (Pagado o Pendiente). Fecha es opcional pero recomendable si quieres que el resumen histórico quede por día. Todo lo demás puede quedar en “Ignorar columna”. Si eliges Canal = Presencial, la página organizará esas ventas como compras presenciales con fecha.

Valores por defecto

Se usan solamente cuando el Excel no tenga una columna relacionada con ese dato.

Recomendado para hojas históricas simples con Cliente + Total + Pagado/Pendiente. Desmárcalo solo si varias filas del mismo cliente pertenecen al mismo pedido/live.

Relacionar columnas

* Para ventas necesitas Precio/Total. Cliente es obligatorio salvo cuando el canal por defecto sea Presencial; ahí puede quedar vacío. Para gastos necesitas Monto; fecha y categoría pueden usar los valores por defecto.

Respaldo y exportación

Modo de almacenamiento: detectando…
Las fotos y pedidos se guardan en este navegador. Descarga respaldos con frecuencia, especialmente antes de cambiar de celular, computadora o borrar los datos del navegador.
Importar / Fusionar respaldo: conserva todo lo que ya tienes y agrega únicamente registros nuevos. Los duplicados se omiten y tu configuración actual no se reemplaza.
Restaurar solo en PC: reemplaza los datos locales pero no modifica Supabase.
Restaurar en PC + nube: hace que la información operativa de Supabase coincida con ese respaldo. Los datos de nube que no estén en la copia pueden eliminarse.

Antes de una restauración PC + nube se mostrará un resumen del archivo y se pedirá confirmación. Los usuarios y roles de acceso no se modifican.

⚠️ Borrado general

Elimina TODAS las facturas, ventas/prendas, pagos, entregas y gastos de Supabase. Conserva usuarios, roles, tablas y configuración.
